# Bluefin AI Demo

This repository contains a zero-dependency HTML presentation for a new project I am starting called **Bluefin**.

## The Idea: Bluefin

Bluefin is a business-first AI agent application designed to solve common pain points for business users interacting with AI:
- **Business-Friendly Outputs**: Generates documents directly in formats users need (like Google Docs or DOCX) rather than raw markdown.
- **Cost Conscious**: Automatically selects the right AI model for every task to keep costs under control.
- **Secure**: Offers on-prem and hyper-secure deployments.

The entire experience is delivered as a single HTML file driven by scroll-based animations to demonstrate the product's value proposition without complex setups.
